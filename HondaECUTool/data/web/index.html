Catatan Pembaruan & Perbaikan (v3.4.2 Changelog):
  • Redesain UI/UX ECU Remap Studio: Tampilan tab Write Flash berbasis alur langkah (Step-by-Step), hero status bar, indikator baterai 12.4V, dan progress bar real-time (Speed KB/s & ETA).
  • Perbaikan Dialog File macOS Finder: Dukungan penuh untuk PyWebView native dialog `.bin` / `.hex` dan pemilih file HTML tanpa benturan dialog ganda.
  • Dual Upload API & Binary Stream: Dukungan `multipart/form-data` serta pengiriman data biner langsung `ArrayBuffer` dengan header `X-Filename`.
  • Proteksi Hardware ECU Fisik: Memastikan flash ke motor asli berjalan ke hardware K-Line FTDI (tidak secara diam-diam masuk ke mode virtual jika kabel belum terhubung).
  • Sinkronisasi Buffer Lintas Proses: Sinkronisasi otomatis file BIN yang dibuka dari Map Editor / Open File langsung ke memori server `127.0.0.1:8080`.
  • Fix Absolute Base URL Fetch: Penanganan URL fetch API berbasis `http://127.0.0.1:8080` untuk mencegah kegagalan pada skema `file://` di aplikasi desktop bundle.
  • Perbaikan Syntax & WebSocket Handler: Pemulihan penuh penanganan progress event WebSocket dan tombol recovery bootloader.
