CARA AKTIVASI SOFTWARE PERTAMA KALI:
------------------------------------------------------------
1. Jalankan aplikasi "JRT_Tech_ANALIST_Pro.exe".
2. Pada layar pertama kali buka, akan muncul jendela "LICENSE ACTIVATION REQUIRED".
3. Salin/Copy Kode Hardware ID (HWID) laptop yang tertera (contoh: JRT-884A-99F1-33BC).
4. Kirimkan Kode HWID tersebut kepada Admin JRT Tech via WhatsApp.
5. Admin akan meng-generate Kunci Lisensi khusus untuk laptop Anda menggunakan software Keygen.
6. Masukkan Kunci Lisensi pada kolom aktivasi lalu klik "ACTIVATE JRT TECH LICENSE".
7. Aplikasi siap digunakan secara penuh dan terkunci aman pada laptop Anda.
